# 化工生产中的重要非金属元素

## 第一节 硫及其化合物
1. 硫
   1. 位置: 第三周期, 第VI族
   2. 物理性质: 黃色晶体, 难溶于水, 易溶于$CS_2$
   3. 化学性质:
      1. 氧化性: $S + 2Cu \stackrel{\triangle}{=} Cu_2S$
      2. 还原性: $S + O_2 \stackrel{\triangle}{=} SO_2$
2. 二氧化硫
   1. 制备: $S + O_2 = 2SO_2$
   2. 性质:
      1. 物理性质: 无色气体, 刺激性气味, 溶于水
      2. 化学性质:
         1. 还原性: $2SO_2 + O_2 = 2SO_3$
         2. 氧化性: $SO_2 + 2H_2S = 3S + 2H_2O$
         3. 漂白性: 使品红褪色(加热重新显色)
         4. $SO_2 + H_2O \rightleftharpoons H_2SO_3$
            1. 酸性: $SO_2 + 2NaOH = Na_2SO_3 + 2H_2O$
            2. 强酸制弱酸: $Na_2CO_3 + SO_2 = Na_2SO_3 + CO_2$, $Na_2SO_3 + H_2SO_4 = Na_2SO_4 + H_2O + SO_2\uparrow$
      3. 检验: 品红褪色, 加热显色
3. 硫酸
   1. 制备
      1. $S + O_2 \stackrel{\triangle}{=} 2SO_2$
      2. $SO_2 + O_2 \stackrel{\triangle, V_2O_5}{=} 2SO_3$
      3. $SO_3 + H_2O = H_2SO_4$
   2. 性质
      1. 稀: 酸性($H_2SO_4 \rightleftharpoons 2H^+ + SO_4^{2-}$)
      2. 浓: 强氧化性($2H_2SO_4(浓) + Cu \stackrel{\triangle}{=} CuSO_4 + H_2O + SO_2\uparrow$, $2H_2SO_4(浓) + C \stackrel{\triangle}{=} H_2O + 2SO_2\uparrow + CO_2\uparrow$)
   3. 检验($SO_4^{2-}$)
      1. $HCl$: 排除$SO_3^{2-}, Ag^+$
      2. $BaCl_2$: 生成白色沉淀$BaSO_4$

## 第二节 氮及其化合物
1. 氮
   1. 位置: 第二周期, 第V族
   2. 性质
      1. 物理: 无色无味, 常温稳定
      2. 化学
         1. 氧化性: $N_2 + 3H_2 \stackrel{高温 高压 催化剂}{\rightleftharpoons} 2NH_3$, $N_2 + 3Mg \stackrel{点燃}{=} Mg_3N_2$
         2. 还原性: $N_2 + 2O_2 \stackrel{放电 高温}{=} 2NO$
   3. 固氮: 游离态$\rightarrow$化合态
      1. 自然: 闪电, 根瘤菌
      2. 人工: 转化为$NH_3, NO_x$
2. 氮氧化物
   1. $NO$: 无色无味, 不溶于水, 易于$O_2$反应
   2. $NO_2$: 红棕色气体, 刺激性气味, 溶于水($3NO_2 + H_2O = 2HNO_3 + NO$)
3. 硝酸
   1. 制备: $3NO_2 + H_2O = 2HNO_3 + NO$
   2. 性质
      1. 物理: 无色, 易挥发, 刺激性气味
      2. 化学: 强氧化性, 酸性
         1. $4HNO_3(浓) + Cu = Cu(NO_3)_2 + 2H_2O + 2NO_2\uparrow$
         2. $8HNO_3(稀) + 3Cu = 3Cu(NO_3)_2 + 4H_2O + 2NO\uparrow$
      3. 钝化(浓$H_2SO_4, HNO_3$都有): 与铁,铝反应, 生成氧化膜, 阻止进一步反应
4. 氨与氨盐
   1. 氨气
      1. 制备: $N_2 + 3H_2 \stackrel{高温 高压 催化剂}{\rightleftharpoons} 2NH_3$
      2. 性质: 无色气体, 刺激性气味, 极易溶于水(氨气喷泉), 易液化气化(制冷剂)
         1. 弱碱性: $NH_3 + HCl = NH_4Cl(白烟)$
         2. 氨水: $NH_3 \cdot H_2O \rightleftharpoons NH_4^+ + OH^-$
      3. 用途: 化肥

## 第三节 无机非金属材料
1. 硅酸盐(玻璃, 陶瓷, 水泥)
   1. $Na_2SiO_3 + 2HCl = 2NaCl + H_2SiO_3\downarrow$
   2. $Na_2SiO_3 + H_2O + CO_2 = Na_2CO_3 + H_2SiO_3\downarrow$
   3. $Si + 2NaOH + H_2O = Na_2SiO_3 + 2H_2$
2. 新型无机非金属材料
   1. $SiO_2 + 2C \stackrel{高温}{=} Si + CO\uparrow$
   2. 酸性氧化物: $SiO_2 + 2NaOH = Na_2SiO_3 + H_2O$
   3. $F^-$特性: $SiO_2 + 4HF = SiF_4 + 2H_2O$
