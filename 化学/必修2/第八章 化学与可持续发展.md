# 化学与可持续发展

## 资源开发
1. 金属
   1. 热分解法: $2HgO \xlongequal{\triangle} 2Hg + O_2$
   2. 电解法: $2NaCl \xlongequal{电解} 2Na + Cl_2$
   3. 置换法: $Zn + CuSO_4 = ZnSO_4 + Cu$, $Fe_2O_3 + 2Al \xlongequal{高温} 2Fe + Al_2O_3$
2. 海水
   1. $NaCl$
   2. $Br_2$
3. 化石燃料
   1. 干馏: 分解煤
   2. 气化: 煤 $\rightarrow CO + H_2$
   3. 分馏: 物理变化, 多次蒸馏
   4. 裂化裂解: $长链 \rightarrow 短链$

## 合理使用
1. 化肥农药适量使用
2. 不滥用药物
3. 合理使用添加剂

## 绿色化学
1. 设计无毒或低毒的化学合成方法
2. 采用可再生资源
3. 减少能源消耗
4. 降低废物产生
