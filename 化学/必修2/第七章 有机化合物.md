# 有机化合物

## 有机物概述
1. 定义: 含C(不包括CO2, 碳酸盐, 氰化物等)
2. 成键方式: 主要是共价键($C-C, C=C, C \equiv C$)
3. 通性: 通常可燃
4. 相关概念
   1. 同系物: 分子组成相差一个或多个$CH_2$
   2. 同分异构: 分子式相同, 结构不同

## 常见有机物类别
1. 烃: 仅含C和H
   1. 饱和烃: 仅含单键($C-C$)
   2. 不饱和烃: 含有双键($C=C$)或三键($C \equiv C$)
2. 醇: 含有$-OH$
3. 酮: 含有$C=O$
4. 酸: 含有$-COOH$
5. 脂: 含有$-COOR$

## 有机反应
1. 取代(一上一下, 可连续进行): $CH_4 + Cl_2 \rightarrow  CH_3Cl + HCl$
2. 加成(只上不下, 进攻双三键): $C_2H_4 + H_2O \rightarrow CH_3CH_2OH$
3. 加聚(类似加成, 同分子加成): $nC_2H_4 \rightarrow (C_2H_4)_n$
4. 脂化(一种取代, 酸羟基醇氢): $CH_3COOH + C_2H_5OH \xrightarrow[\triangle]{浓H_2SO_4} CH_3COOC_2H_5 + H_2O$
5. 催化氧化(铜银催化, 邻碳羟脱氢): $2C_2H_5OH + O_2 \xrightarrow{Cu/Ag} 2CH_3CHO + 2H_2O$

## 基本营养物质
1. 糖: 多羟基醛, 多羟基酮
   1. 单糖: $C_6H_{12}O_6$ 葡萄糖,果糖
   2. 二糖: $C_{12}H_{22}O_{11}$ 蔗糖, 乳糖
   3. 多糖: $(C_6H_{10}O_5)_n$ 淀粉, 糖原
   4. 检验: 新制$Cu(OH)_2$, 银镜反应
2. 蛋白质
   1. 两性: $-COOH, -NH_2$
   2. 水解
   3. 盐析: 轻金属盐
   4. 变性: 高温, 酸碱, 重金属盐
